Privacy Policy

Last updated 9 October 2026 · App software.basilbase.linkrudder · Developer basilbase · Contact contact@basilbase.com · Türkçe

LinkRudder lets you choose which app opens each web link, and shows what will change in a link before it opens. Your rules stay on your phone. There is no account, no analytics, no advertising and no crash reporting. The app holds the internet permission for exactly one thing: the Resolve short link button, and only after you press it.

The verifiable version

LinkRudder's manifest requests one permission that Android shows in the Play listing: INTERNET. It does not request QUERY_ALL_PACKAGES, ACCESS_NETWORK_STATE, notifications, location, contacts, storage, accessibility or usage access. You can confirm this in the Play listing's permission list or by inspecting the APK.

The app's code makes a network request in one place only: the short-link resolver, which runs after you press Resolve short link and confirm the dialog that names the server it will contact. Opening, choosing, cleaning and unwrapping links all happen on the phone, without the network. Nothing runs in the background, and the clean-up list is never updated over the internet.

What happens when you press "Resolve short link"

Short links (for example a link shortener) only reveal their destination when their server is asked. When you press the button and confirm:

  • LinkRudder sends a request to the server in that link, and follows at most 5 redirects. It asks with HEAD first, and if the server refuses, with a GET limited to one byte. It never reads page content.
  • It sends no cookies, no account, no sign-in data and no device identifier. The request carries the link itself and the user agent LinkRudder.
  • It only contacts secure https servers. A plain http link is not contacted.
  • It never contacts private or local network addresses (for example 192.168.x.x, 10.x.x.x or localhost), also when a redirect points there.
  • Like any web request, the server sees your IP address and the link that was requested. Some links work only once (for example sign-in or payment links); requesting them can use them up. The app warns you when a link looks like one of these.
  • The result is shown to you. Nothing about it is stored or sent anywhere else.

Only the short link you choose to resolve is sent to that link's own server. In Google Play's Data safety section this appears as Web browsing history: collected, optional (only when you press Resolve short link), for app functionality, not shared, encrypted in transit (https only), not stored by LinkRudder.

Permissions in full

This is the complete list.

Permission Why Without it Withdraw
Internet (INTERNET) Only for the Resolve short link button, after you press it. Short links could not be resolved; everything else works the same. Install-time; not revocable. Simply do not press the button.
Default browser (system role, optional) If you choose it, Android sends the web links you tap in most apps to LinkRudder. You can still use LinkRudder from the Share menu or with "Open copied link". Settings › Apps › Default apps › Browser app

The <queries> entry in the manifest lets LinkRudder see only the apps that open web links (browsers and apps with links for particular sites), so it can list them. It cannot see your other apps, and it never reads your app usage.

What LinkRudder does not do

  • It has no server of its own and does not sell or share personal data. Only the short link you choose to resolve is sent to that link's own server.
  • It does not keep a history of the links you open, unless you switch history on yourself (see below). Even then it keeps only the site name, never the full link.
  • It does not read your clipboard in the background. It reads it only when you press "Open copied link" or "Paste".
  • It does not see links that an app opens inside itself, or that Android sends straight to an app with verified links.
  • It does not check whether a site is safe. A cleaned or resolved link is not a checked link.
  • It does not log links. Links can carry sign-in tokens, so they are kept out of the system log.

The signing-certificate fingerprint lets the app notice when a chosen app was replaced by one signed by someone else; the rule then asks instead of opening.

What is deliberately not stored

Full links in history, page content, browsing statistics, usage counts, device identifiers, crash dumps.

Backup

Android cloud backup and device-to-device transfer are switched off for this app, so your rules are not copied into a Google backup. To move them, use Backup › Save to a file, then Load from a file on the other phone. The file is plain JSON. It holds your rules, the default choice and the clean-up switches, and no history or links.

Feedback

The Send feedback screen writes a message and hands it to your own email app, with your phone model, Android version, app version and app language added at the end. LinkRudder does not send it itself; you see the message in your email app before it goes to contact@basilbase.com.

Children

LinkRudder is not directed at children and collects no data from anyone.

Retention and deletion

Everything stays on your phone until you delete it. Privacy › Delete everything removes rules, history, pinned apps and shortcuts. Turning history off deletes the history at once. Uninstalling LinkRudder removes all of its data. If LinkRudder is your default browser, choose another one in the system settings; the app shows a button for this.

Changes

If this policy changes, the date at the top changes with it and the new text replaces this page. Material changes are also described in the app's release notes.
